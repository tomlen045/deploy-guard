🚦 DEPLOY GUARD · 部署安全守卫

今天是周五下午
你确定要部署？

8项安全检查 · 一条命令 · 3秒出判定

每个开发者都干过至少其中一件：

· 周五下午部署，周一早上回来救火
· 没跑测试就上线，"应该没问题吧"
· 改了数据库，没写回滚方案
· 半夜偷偷发包，心想"别被发现"

我做了一个开源工具：deploy-guard。在你执行部署前，帮你自动检查 8 项安全条件。

$ bash deploy-guard.sh

🚫 NO-GO — Fix these first:

• It's Friday afternoon. You KNOW how this ends.

• .env is tracked by git!

⚠️ Found test script — did you run npm test?

Checks: 5 passed · 2 warnings · 2 critical

📋 8项检查

📅 日期检查
周五下午？节假日？凌晨3点？——经典送命时段

📝 Git状态
未提交的修改、未推送的commit、WIP消息

🧪 测试提醒
检测到测试脚本但可能没跑

🔐 密钥泄露
.env 文件被 git 跟踪——数据库密码裸奔中

🏷 TODO检查
暂存的代码里有未完成的 TODO/FIXME

🌿 分支检查
直接在 main 上操作？用 feature branch 吧

💾 磁盘空间
部署到一半磁盘满了才是最惨的

🧠 内存检查
部署过程触发 OOM 就精彩了

🔧 三种使用方式

终端手动检查：
bash deploy-guard.sh

CI/CD 集成：
bash deploy-guard.sh --strict && deploy

跳过周末检查（on-call 用）：
bash deploy-guard.sh --skip-weekend

⚠️ 坦白说

这个工具不会阻止你部署——它只是提醒你"你确定吗？"。最终决定权在你。它也不会替代完整的 CI/CD 流程。它是一个 3 秒安全网，不是银弹。
